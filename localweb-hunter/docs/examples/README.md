# プロンプトの出力例

`src/lib/prompt/sitePrompt.ts` が生成するプロンプトと、それを実際に通した結果です。
プロンプトを変更したときに「出力の質が落ちていないか」を見比べるために置いています。

| ファイル | 内容 |
|---|---|
| `prompt-seitai.txt` | 整体院向けに生成されたプロンプト（実データ入り） |
| `prompt-ramen.txt` | 飲食店向け。同じ仕組みで配色・構成・禁止表現が変わることの確認用 |
| `sample-seitai.html` | `prompt-seitai.txt` を通して出てきたサイト |

## sample-seitai.html で確認できること

- 写真が1枚も無い状態で、完成品として成立している
- 「初めての方へ」の5ステップが、この業種の不安（痛いのか・何をされるのか）に直接答えている
- 電話ボタンが画面下部に固定され、スクロールのどこからでも押せる
- 「本日営業中」が営業時間データから自動で判定される（手で書き換える運用にしない）
- 不明な項目（メニュー価格・資格・駐車場）を捏造せず、確認が必要なことが分かる形で置いている
- `noindex` と、提案用サンプルである旨のフッター表記が入っている
- 「治る」「効果があります」などの、この業種で使えない表現を含んでいない

ブラウザで直接開けます（ビルド不要）。
