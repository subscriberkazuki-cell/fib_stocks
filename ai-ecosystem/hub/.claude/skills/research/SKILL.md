# /research — 出典つき調査

調査テーマ: $ARGUMENTS

## 目的
意思決定に使える、出典の確かな調査結果を作る。量より正確さを優先する。

## 手順

1. **PLAN** — テーマを、答えるべき問い（3〜6個）に分解する。対象期間・地域・定義が曖昧なら、結果が大きく変わる点だけ確認する
2. **記憶の確認** — Vault の `AI_Hub/03_Research/` と `02_Knowledge/` を検索し、既存の調査があれば再利用する（古ければ更新扱いにする）
3. **収集** — `research-analyst` に問いを渡す。互いに独立した問いが複数あるときだけ、最大2体で並列にする
4. **統合** — 結果をまとめ、矛盾する情報は両方の出典を示して扱いを判断する
5. **検査** — `quality-reviewer` に、レポートと元の問いを渡す
6. **修正** — 指摘を直す（原則2回まで）。直さない指摘は理由を書く
7. **保存** — `AI_Hub/03_Research/YYYY-MM-DD_<テーマ>.md` に保存し、`/remember` の手順で MEMORY_INDEX に1行追加する

## 品質基準
- すべての数値に「出典URL・公開日・対象期間」がある
- 事実・推測・未確認が分かれている
- 結論が3行以内で書かれ、根拠と対応している
- 独立レビューを通っている（判定と主な指摘をレポート末尾に残す）

## 出力形式

```
# <テーマ>（調査日 YYYY-MM-DD）

## 結論
## 主要な事実（出典つき）
## 解釈・推測
## 反対の見方・リスク
## 未確認の点・次に調べること
## 出典一覧
## レビュー記録（判定 / 主な指摘 / 対応）
```
