# /stock-a — 株式分析A

対象: $ARGUMENTS

## 絶対のルール
- **指定されたティッカーと決算期を厳守する。** 別の期の数値で代用しない。指定がなければ「最新の正式決算」を使い、その期を明記する
- 一次資料（決算短信・10-Q / 10-K・8-K の決算リリース・決算説明資料・決算説明会の発言録）を最優先する
- 数値はすべて出典と対象期間を付ける。見つからない項目は「未確認」と書き、推測で埋めない
- 投資判断の情報提供であり、売買の推奨はしない

## 手順

1. **特定** — 企業名・ティッカー・上場市場・決算四半期・決算発表日・会計年度（期末月）を確定する
2. **一次資料の収集** — `research-analyst` に、上の期の一次資料と市場予想（コンセンサス）を集めさせる
3. **分析** — 下の「出力形式」の各項目を埋める
4. **検査** — `quality-reviewer` に渡し、主要数値（売上・営業利益・EPS・FCF）を最低4つ出典と照合させる
5. **修正** — 指摘を直す（原則2回まで）
6. **保存** — `AI_Hub/01_Projects/Investment/<TICKER>/YYYY-MM-DD_<決算期>_A.md` に保存し、MEMORY_INDEX に1行追加する

## 出力形式

```
# <企業名>（<TICKER>） <決算期> — 株式分析A

## 基本情報
- 企業名 / ティッカー / 市場
- 決算四半期 / 決算発表日 / 会計年度（期末月）

## 業績（前年同期比・前期比）
| 指標 | 実績 | 前年同期 | 伸び率 | 市場予想 | 差 |
（売上・営業利益・EPS・営業CF・FCF。FCF = 営業CF − 設備投資、式を明記）

## 実際に利益を生んでいる事業
## 成長ドライバー（TOP1〜2に限定）
- TOP1: 何が・なぜ伸びているか・どの数字で確認できるか
- TOP2:

## セグメント別の寄与（売上・利益の構成比と伸び）
## 中国依存度・サプライチェーン・供給制約
## KPI と市場予想の差
## バリュエーション（PER・EV/売上・EV/EBITDA など、算出日と株価を明記）
## ブル要因 / ベア要因
## Core Definition（この会社は何で稼ぐ会社か、を1〜2文で）
## 出典一覧
## レビュー記録
```

成長ドライバーは3つ以上挙げない。決めきれないときは、利益寄与の大きい順に2つに絞り、絞った理由を書く。
