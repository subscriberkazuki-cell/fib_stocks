# /content-production — コンテンツ制作

依頼: $ARGUMENTS

## 守ること
- **投稿・公開・予約投稿はしない。** 成果物は下書きとして保存し、公開はオーナーが行う
- 字幕や文字起こしを取得できなかったら、**取得できなかったとはっきり報告する。** 動画の中身を推測で書かない
- 他者の動画・記事の文章をそのまま転載しない。要約と自分の言葉での再構成にとどめ、出典を明記する
- 投資を扱う内容（決算予想チャンネル）は、断定的な売買推奨をしない

## YouTube URL から記事を作る手順

1. **字幕の取得** — 使える手段を順に試す
   - `yt-dlp --skip-download --write-auto-subs --sub-langs ja,en --sub-format vtt -o <一時フォルダ>` （yt-dlp が導入済みの場合のみ。未導入なら導入はオーナーの承認を得る）
   - 取得できなければ、そこで止めて報告する
2. **内容分析** — 主題・主張・根拠・具体例・数字を抜き出す。数字は動画内の発言であることを明記する
3. **要点抽出** — 読者にとっての要点を3〜7個
4. **記事構成** — 想定読者・検索意図・見出し構成（SEO を考慮しつつ、中身のない見出しは作らない）
5. **ブログ記事** — 構成に沿って執筆。出典（動画URL・チャンネル名）を明記
6. **SNS投稿案** — X 用（短文3案）、必要なら他の媒体
7. **品質チェック** — `quality-reviewer` に、事実の正確さ・元動画との食い違い・日本語の品質を検査させる
8. **修正**（原則2回まで）
9. **保存** — `AI_Hub/01_Projects/Content/<媒体>/YYYY-MM-DD_<タイトル>.md`

## その他の制作物
- **広告動画**：構成 → 秒単位の設計表（時間・映像・テロップ・ナレーション・音）→ 素材リスト。生成・合成ツールは導入済みのものだけ使い、未導入なら必要なツールと費用を提案して止まる
- **サムネイル**：コンセプト3案と文言。画像生成は利用可能なツールがある場合のみ
- **「なんでもないもの博物館」**：ブランドの語り口は Vault の `01_Projects/Content/` にある指針に従う。なければ作成時に確認する

## 出力形式
媒体ごとに、本文・メタ情報（タイトル案・説明文・タグ）・出典・レビュー記録をまとめる。
