## 2026-11-14 AIエコシステムの初期構成
- **司令塔は Claude Code。** タスク分解・委任・統合・品質管理・記録を担う
- **長期記憶は Obsidian Vault の AI_Hub。** Claude Code の自動メモリ（auto memory）は二重管理を避けるため、AI Hub では無効にする
- **課金は Claude Pro の契約内。** API キーによる従量課金は設定しない。外部AIは追加料金がないと確認できたものだけ使う
- **専門エージェントは3体から。** research-analyst / quality-reviewer（Red Team）/ technical-qa。同時稼働は2体まで
- **品質管理は別コンテキストで。** 成果物は作成者以外のエージェントが検査する。修正は原則2回まで
- **安全装置は文章に頼らない。** 削除・push・デプロイ・送信・課金は権限ルールと Hooks で止める
