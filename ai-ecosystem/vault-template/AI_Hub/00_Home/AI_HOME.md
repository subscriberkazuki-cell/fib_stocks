# AI_HOME

AI（Claude Code）が毎セッションの最初に読む入口です。短く保ってください（索引として自動で読み込まれます）。

## この Vault での AI の居場所
- AI が読み書きするのは `AI_Hub/` の中だけです。それ以外のノートは、指示があったときに読むだけにします
- 記憶の目録: [[MEMORY_INDEX]]
- プロジェクトの進行状況: [[PROJECT_INDEX]]
- 決定事項の履歴: [[DECISIONS]]
- オーナーの判断基準と好み: [[USER_PROFILE]]

## フォルダの使い分け
| フォルダ | 入れるもの |
|---|---|
| 00_Home | 索引・決定事項・プロフィール |
| 01_Projects | プロジェクトごとの状況・決定・成果物 |
| 02_Knowledge | 分野ごとの知見・手順・失敗の記録 |
| 03_Research | 調査レポート（日付つき） |
| 04_Outputs | 完成した成果物 |
| 05_Daily | その日のメモ（AI は必要なときだけ書く） |
| 90_Archive | 使わなくなったもの（削除はしない） |

## 記憶のルール（要約）
- 1ノート1話題。既存ノートがあれば更新する
- 決定と仮説を区別する。方針が変わったら古いノートは `superseded` にする
- 調査結果には出典を残す。秘密情報は保存しない
