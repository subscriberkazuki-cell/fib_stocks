# USER_PROFILE — オーナーの判断基準と好み

AI が判断に迷ったときに参照する、オーナーの基準です。変わったら `/remember` で更新します。

## 基本方針
- AI に丸投げせず、「指示 → 分解 → 専門エージェント → 外部ツール → 品質検査 → 修正 → 成果物 → 記憶保存」の流れで仕事をさせたい
- 最終的な意思決定（特に投資・お金・公開）は自分が行う
- 必要なものだけ導入する。複雑すぎる環境にしない
- 新規の有料契約・API 従量課金は原則しない。Claude Pro の契約内で動かす
- 不要な確認は減らしたいが、外部送信・公開・削除・課金は必ず確認してほしい

## 分析の基準
- 一次資料を最優先。ティッカーと決算期は厳守
- 成長ドライバーは TOP1〜2 に絞る
- 事実と推測を分ける。出典・公開日・対象期間を必ず付ける
- 事業案は「実際に成立するか」を重視し、反対意見・失敗シナリオを積極的に出してほしい

## 主な活動領域
- 株式投資・企業分析（独自の分析A・B）
- 新規ビジネス・スタートアップ
- THEMORA（決算前後の株価変動・統計の情報サービス）
- FRED（暗号資産の Funding Rate アービトラージ）
- BTC トレード BOT（Bookmap + Python。売買判断と発注は人間の管理下）
- コンテンツ制作（決算予想の YouTube、「なんでもないもの博物館」、SNS、広告動画、ブログ）
